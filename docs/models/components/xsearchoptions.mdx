---
title: "XSearchOptions"
---

Enable SpaceXAI X (Twitter) search alongside native web search, with optional filters. Only applies to SpaceXAI endpoints with native search; omit to search the web only. X search is billed separately by SpaceXAI, per post and per user profile fetched.


## Fields

| Field                                                                                     | Type                                                                                      | Required                                                                                  | Description                                                                               | Example                                                                                   |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `AllowedXHandles`                                                                         | []`string`                                                                                | :heavy_minus_sign:                                                                        | Only include posts from these X handles (max 20). Cannot be used with excluded_x_handles. | [<br/>"OpenRouterAI"<br/>]                                                                |
| `EnableImageUnderstanding`                                                                | `*bool`                                                                                   | :heavy_minus_sign:                                                                        | Analyze images attached to matching posts.                                                |                                                                                           |
| `EnableVideoUnderstanding`                                                                | `*bool`                                                                                   | :heavy_minus_sign:                                                                        | Analyze videos attached to matching posts.                                                |                                                                                           |
| `ExcludedXHandles`                                                                        | []`string`                                                                                | :heavy_minus_sign:                                                                        | Exclude posts from these X handles (max 20). Cannot be used with allowed_x_handles.       | [<br/>"spamaccount"<br/>]                                                                 |
| `FromDate`                                                                                | [*types.Date](../../types/date.mdx)                                                        | :heavy_minus_sign:                                                                        | Start of the post date range (ISO 8601 date, e.g. "2025-01-01").                          | 2025-01-01                                                                                |
| `ToDate`                                                                                  | [*types.Date](../../types/date.mdx)                                                        | :heavy_minus_sign:                                                                        | End of the post date range (ISO 8601 date, e.g. "2025-12-31").                            | 2025-12-31                                                                                |
