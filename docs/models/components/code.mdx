## Supported Types

### 

```go
code := components.CreateCodeStr(string{/* values here */})
```

### 

```go
code := components.CreateCodeInteger(int64{/* values here */})
```

## Union Discrimination

Use the `Type` field to determine which variant is active, then access the corresponding field:

```go
switch code.Type {
	case components.CodeTypeStr:
		// code.Str is populated
	case components.CodeTypeInteger:
		// code.Integer is populated
}
```
