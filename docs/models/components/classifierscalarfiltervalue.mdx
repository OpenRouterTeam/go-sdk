title: "ClassifierScalarFilterValue"
---

Scalar (string or number) filter value.


## Supported Types

### 

```go
classifierScalarFilterValue := components.CreateClassifierScalarFilterValueStr(string{/* values here */})
```

### 

```go
classifierScalarFilterValue := components.CreateClassifierScalarFilterValueNumber(float64{/* values here */})
```

## Union Discrimination

Use the `Type` field to determine which variant is active, then access the corresponding field:

```go
switch classifierScalarFilterValue.Type {
	case components.ClassifierScalarFilterValueTypeStr:
		// classifierScalarFilterValue.Str is populated
	case components.ClassifierScalarFilterValueTypeNumber:
		// classifierScalarFilterValue.Number is populated
}
```
