---
title: "BatchListStatus"
---

A batch status that is durably represented by the list data source. `finalizing` and `cancelling` are not accepted because stored jobs collapse those phases into `in_progress`.

## Example Usage

```go
import (
	"github.com/OpenRouterTeam/go-sdk/models/components"
)

value := components.BatchListStatusValidating

// Open enum: custom values can be created with a direct type cast
custom := components.BatchListStatus("custom_value")
```

| `BatchListStatusValidating` | validating                  |
| `BatchListStatusInProgress` | in_progress                 |
