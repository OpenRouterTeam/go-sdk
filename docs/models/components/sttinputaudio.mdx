---
title: "STTInputAudio"
---

Audio to transcribe: inline base64 bytes, or a URL the provider downloads directly.


## Supported Types

### STTInlineInputAudio

```go
sttInputAudio := components.CreateSTTInputAudioSTTInlineInputAudio(components.STTInlineInputAudio{/* values here */})
```

### STTURLInputAudio

```go
sttInputAudio := components.CreateSTTInputAudioSTTURLInputAudio(components.STTURLInputAudio{/* values here */})
```

## Union Discrimination

Use the `Type` field to determine which variant is active, then access the corresponding field:

```go
switch sttInputAudio.Type {
	case components.STTInputAudioTypeSTTInlineInputAudio:
		// sttInputAudio.STTInlineInputAudio is populated
	case components.STTInputAudioTypeSTTURLInputAudio:
		// sttInputAudio.STTURLInputAudio is populated
}
```
