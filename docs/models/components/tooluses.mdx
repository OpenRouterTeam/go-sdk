## Union Discrimination

Use the `Type` field to determine which variant is active, then access the corresponding field:

```go
switch toolUses.Type {
	case components.ToolUsesTypeEvaluated:
		// toolUses.ToolUsesEvaluated is populated
	case components.ToolUsesTypeSkipped:
		// toolUses.ToolUsesSkipped is populated
	case components.ToolUsesTypeUnavailable:
		// toolUses.ToolUsesUnavailable is populated
	default:
		// Unknown type - use toolUses.GetUnknownRaw() for raw JSON
}
```
