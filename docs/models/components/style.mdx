title: "Style"

## Supported Types

### 

```go
style := components.CreateStyleStr(string{/* values here */})
```

### 

```go
style := components.CreateStyleBoolean(bool{/* values here */})
```

### 

```go
style := components.CreateStyleNumber(float64{/* values here */})
```

## Union Discrimination

Use the `Type` field to determine which variant is active, then access the corresponding field:

```go
switch style.Type {
	case components.StyleTypeStr:
		// style.Str is populated
	case components.StyleTypeBoolean:
		// style.Boolean is populated
	case components.StyleTypeNumber:
		// style.Number is populated
}
```
