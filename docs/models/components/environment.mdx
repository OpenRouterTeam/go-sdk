## Supported Types

### 

```go
environment := components.CreateEnvironmentStr(string{/* values here */})
```

### ArmorEnvironmentEntry

```go
environment := components.CreateEnvironmentArmorEnvironmentEntry(components.ArmorEnvironmentEntry{/* values here */})
```

## Union Discrimination

Use the `Type` field to determine which variant is active, then access the corresponding field:

```go
switch environment.Type {
	case components.EnvironmentTypeStr:
		// environment.Str is populated
	case components.EnvironmentTypeArmorEnvironmentEntry:
		// environment.ArmorEnvironmentEntry is populated
}
```
