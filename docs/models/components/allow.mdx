title: "Allow"

## Supported Types

### 

```go
allow := components.CreateAllowStr(string{/* values here */})
```

### ArmorRule

```go
allow := components.CreateAllowArmorRule(components.ArmorRule{/* values here */})
```

## Union Discrimination

Use the `Type` field to determine which variant is active, then access the corresponding field:

```go
switch allow.Type {
	case components.AllowTypeStr:
		// allow.Str is populated
	case components.AllowTypeArmorRule:
		// allow.ArmorRule is populated
}
```
