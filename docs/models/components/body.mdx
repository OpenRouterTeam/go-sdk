## Union Discrimination

Use the `Type` field to determine which variant is active, then access the corresponding field:

```go
switch body.Type {
	case components.BodyTypeBodyChatCompletion:
		// body.BodyChatCompletion is populated
	case components.BodyTypeOpenResponsesResult:
		// body.OpenResponsesResult is populated
	case components.BodyTypeBodyMessage:
		// body.BodyMessage is populated
	case components.BodyTypeBodyList:
		// body.BodyList is populated
}
```
