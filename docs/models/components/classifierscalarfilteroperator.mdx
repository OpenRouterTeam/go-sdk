Equality operator taking a scalar filter value. Ordered comparisons are not available because classification values are strings.

## Example Usage

```go
import (
	"github.com/OpenRouterTeam/go-sdk/models/components"
)

value := components.ClassifierScalarFilterOperatorEq

// Open enum: custom values can be created with a direct type cast
custom := components.ClassifierScalarFilterOperator("custom_value")
```
